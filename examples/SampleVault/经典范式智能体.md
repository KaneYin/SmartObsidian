# 什么是 Agent？
Agent 和普通大模型的区别就是，拥有一个核心的运作闭环：**感知 - 规划 - 行动 - 再感知**

背后的三件核心事件：
- 工具调用
- 记忆机制
- 多步推理和自我纠错

智能体，核心能力在于将大语言模型的推理能力与外部世界联通，能够自主地理解用户意图、拆解复杂任务，通过代码解释器，搜索引擎、API 等一系列工具，来获取信息、执行操作、最终达成目标。

智能体中最具代表性的三种：
- ReAct: 一种将 “思考” 和 “行动” 紧密结合的范式，让智能体能够边想边做，动态调整。
- Plan-And-Solve: 智能体现生成一个完整的行动计划，然后严格执行。
- Reflection：通过自我批判和修正来优化结果。

#  Workflow 和 Agent 的差异
简单来说，Workflow 是让 AI 按部就班地执行指令，Agent 是赋予 AI 自由度去自主达成目标。

工作流是一种传统的自动化范式，核心是对一系列任务或步骤进行预先定义的、结构化的编排。本质是上一个精确的、静态的流程图，规定了在何种条件下，以何种顺序执行那些操作。

而基于 LLM 的智能体是一个具备自主性以目标为导向的系统，不仅仅是执行预设指令，而是能够在一定程度上理解环境、推理、计划、并采取行动来达到最终目标。LLM 在其中相当于 ”大脑“。
